# Io_Projekt_BiletyNaWydarzenia
Projekt edukacyjny, którego celem jest stworzenie systemu obsługującego sprzedaż biletów na wydarzenia.
Podczas realizacji projektu wykonujący go studenci powinni nabrać umiejętności tworzenia oprogramowania w zespole, pracy w systemie kontroli wersji, a także tworzyć czytelny kod dla innych programistów.
